# Сервис прогнозирования спроса

## Обзор проекта

Demand Forecasting ML Service — это веб-приложение на основе машинного обучения, предназначенное для прогнозирования спроса на товары и оценки бизнес-выручки с использованием исторических данных.

### Основные возможности

- Прогнозирование спроса с помощью ML
- Backend на FastAPI
- Dashboard на Streamlit
- Система кредитов и биллинга
- Имитация оплаты
- Docker-развертывание
- Поддержка английского и русского языков
- Прогнозирование выручки

## Pipeline машинного обучения

### Подготовка данных

- Преобразование дат
- Удаление пропущенных значений
- Агрегация по месяцам
- Feature engineering

### Используемые признаки

- Код товара
- Склад
- Категория товара
- Месяц / сезон
- Lag-признаки
- Скользящие средние
- Смоделированная цена

### Модель

- HistGradientBoostingRegressor

### Метрики

- MAE
- RMSE
- Сравнение с baseline-моделью
